# SWARM EVOLVE-X

A small, reproducible design loop for the Meta Global AI hackathon.

You give it a gripper objective, bounds, a seed, and a simulator budget. A planner proposes where to search. A deterministic surrogate scores every design. An adversary looks for valid stress cases inside a declared envelope. Evolution spends the same budget three ways: random search, evolution alone, and evolution plus the adversary. Finalists are frozen before they see the holdout set.

The optional second domain is a 24-hour energy balance with the same runner. It is a teaching model, not a grid study.

## What is novel here

The model does not invent the physics and it does not run code. It can only return a hypothesis, a region inside the bounds, and an action from an allowlist. The simulator is the measurement. Every result stores the evaluator version, the assumptions hash, the seeds, and the holdout fingerprint.

## Layout

```
backend/app/sim/gripper.py     analytic gripper score
backend/app/sim/energy.py      optional daily energy balance
backend/app/search/            random, evolutionary, and adversarial search
backend/app/agents/            Meta client, mock planner, rule planner
backend/app/orchestration/     plan → search → frozen holdout
frontend/                      run form, gripper figure, charts, provenance
docs/                          contract, assumptions, holdout numbers
experiments/                   example config, manual check, recorded run
```

## Run it locally

Python 3.10+ and Node 20+ are enough. Copy `.env.example` to `.env` and leave `ENABLE_META=false` until you have a key. Do not commit `.env`.

```powershell
cd swarm-evolve-x
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r backend\requirements.txt -r backend\requirements-dev.txt
cd backend
python -m pytest
python -m uvicorn app.main:app --reload --port 8000
```

In a second terminal:

```powershell
cd swarm-evolve-x\frontend
npm install
npm run dev
```

Open `http://localhost:3000`. The API docs are at `http://127.0.0.1:8000/docs`.

If the API is down, use **Replay recorded gripper run**. That file is `frontend/public/demo/hero.json`, generated by:

```powershell
cd backend
python scripts\export_hero.py
python scripts\evaluate.py
```

`evaluate.py` rewrites `docs/evaluation.md` from a fresh three-seed holdout. Do not paste numbers into that file by hand.

## Model use

Set `ENABLE_META=true` and `MODEL_API_KEY` only on the server. The client posts to `META_BASE_URL` (`https://api.meta.ai/v1` by default) at `/responses`, with timeout, retry, and a six-call cap. The dashboard provider switch cannot reveal the key. If the flag is off, or the call fails, the run continues with the mock or rule planner and says so in the provenance log.

## Metrics

Search calls are split equally across random, evolutionary, and adversarial search. Adversarial trials count against that method's own budget. Holdout evaluations are extra and are not used to pick the winner.

The pre-registered finalist is the best train-core design under feasibility-first ranking. The comparison table on the dashboard is that design's holdout score.

## Safety and limits

- No model output is passed to `eval`, `exec`, or a shell.
- Design bounds cannot exceed the absolute envelopes in `docs/spec.md`.
- The gripper and energy scores are surrogates. Their limits are listed on the provenance tab and in `docs/assumptions.md`.
- A negative holdout result is reported as a negative result.
